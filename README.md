# Seven Kingdoms II M3 테스터판

Steam의 **Seven Kingdoms 2 HD**가 설치되어 있어야 합니다. 원작 게임 파일은 포함되어 있지 않으며, 이용자 PC의 설치본에서 가져옵니다.

Enlight Software와 관계없는 비공식 팬 확장입니다. 엔진의 GPL v2 소스는 게임 설치 폴더의 `source/`에, MIT 라이선스 런처 소스는 릴리스의 `SK2M3Launcher-source.zip`에 있습니다.

Seven Kingdoms II M3 tester release. **Steam Seven Kingdoms 2 HD must be installed.** Original game files are not included; the installer uses the copy on your PC.

This is an unofficial fan expansion, unaffiliated with Enlight Software. GPL v2 engine sources are installed in `source/`; MIT launcher sources are provided in `SK2M3Launcher-source.zip` in the release.
