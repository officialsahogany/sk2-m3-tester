# Seven Kingdoms II: Titan Wars Mod — v25

Seven Kingdoms II: Titan Wars Mod는 비공식 팬 모드이며 Enlight 공식판이 아닙니다. 옛 이름은 M3입니다.

Steam Seven Kingdoms 2 HD 원작이 필요합니다. 2.10e와 2.20 베타를 지원하며 원작 파일은 배포물에 포함하지 않습니다.

1. 런처 ZIP을 풀고 `SK2M3Launcher.exe`를 실행합니다.
2. 모드 폴더로 새 빈 폴더 또는 기존 M3/Titan Wars 설치 폴더를 선택합니다.
3. 업데이트 확인 → 게임 설치/업데이트 → 게임 시작을 누릅니다.

Steam 폴더는 원작 확인 창에서 선택합니다. 원작과 모드는 별도 폴더여야 하며 서로 다른 드라이브에 있어도 됩니다. 원작 확인 실패 시 표시된 파일명을 확인하고 Steam 무결성 검사를 진행하세요.

이번 v25는 2026-10-29 업데이트 요청 시점에 메인에 반영된 게임을 포함합니다. 프라이탄 AI 개막·집결과 경제, 군대 유지비, 마을 농부·수비병과 망루, 소환수 전투, 티탄 정보와 호위, 리플레이 조작 및 여러 수정이 반영됩니다. 상세한 변경 문서는 설치 폴더의 `docs`에 있습니다.

런처는 원작 확인 증명 오류가 수정된 1.24 그대로입니다. 1.21·1.22·1.23은 먼저 1.24로 자동 업데이트하며, 이미 1.24라면 게임 업데이트만 받습니다. 게임 실행 중에는 종료한 뒤 업데이트하세요.

저장·설정·리플레이 파일은 보존됩니다. 다만 v24·v24b·v24c와 그 이전에 녹화한 리플레이는 기록 당시 실행 파일과 자료가 달라 이번 업데이트 후 재생할 수 없습니다. 파일 자체는 삭제하지 않습니다. v25에서 새로 만든 리플레이는 재생할 수 있습니다. 세계정복 모드는 리플레이를 기록하지 않습니다. 새 버전에서 저장한 게임은 이전 버전에서 열 수 없습니다.

## English

Seven Kingdoms II: Titan Wars Mod (formerly M3) is an unofficial fan mod, not an official Enlight release. An owned Steam copy of Seven Kingdoms 2 HD is required; 2.10e and the 2.20 beta are supported. Original game files are not included.

Extract the launcher ZIP and run `SK2M3Launcher.exe`. Select an empty mod folder or your existing M3/Titan Wars folder, then Check for updates → Install game/Update → Start game. Select the Steam folder only for original verification; separate folders on different drives are supported.

v25 packages the published main game at the October 29 request time, including Fryhtan AI and economy, army upkeep, town and watchtower improvements, summoned-unit combat, Titan information/escort and replay fixes. Launcher 1.24 is unchanged. Older 1.21–1.23 launchers update to 1.24 first.

Saves, settings and recording files are kept. Recordings made in v24/v24b/v24c or earlier cannot play after this in-place update because the recorded executable/data differ. New v25 recordings can play; World Conquest does not record replays. Saves created by the new game cannot be opened by an older game version.

## 中文

Seven Kingdoms II: Titan Wars Mod（原名 M3）是非官方同人模组，并非 Enlight 官方版本。需要拥有 Steam Seven Kingdoms 2 HD 原版；支持 2.10e 和 2.20 测试版。本包不包含原版游戏文件。

解压启动器 ZIP，运行 `SK2M3Launcher.exe`，选择新的空模组文件夹或现有 M3/Titan Wars 文件夹，然后检查更新 → 安装游戏/更新 → 启动游戏。仅在原版验证窗口中选择 Steam 文件夹；原版与模组必须分开，可以位于不同磁盘。

v25 包含 10 月 29 日提出更新时已经发布到主游戏的改动，包括弗莱坦 AI 与经济、军队维护费、城镇与瞭望塔、召唤单位战斗、泰坦信息与护卫及回放修复。启动器保持 1.24；旧版 1.21–1.23 会先自动升级至 1.24。

保留存档、设置和录像文件，但 v24/v24b/v24c 及更早版本的录像因执行文件和数据变化，在本次原地更新后无法播放。录像文件不会删除；v25 新录像可以播放。世界征服模式不记录回放。新版存档不能用旧版游戏读取。
